# SlideME Reborn v0.1

An unofficial fan archive for legacy Android apps.
Made for phones that are stuck on Android 4.4 KitKat and below.

## What is this?
SlideME Reborn helps you find apps that still work on old Android phones.
We do NOT host any APKs. All download links go to APKMirror, APKPure, Aptoide, LiteAPKs, etc.

This project is dedicated to the original SlideME team 2010-2016.

## Features
- [x] 100% Free, No ads
- [x] Links to multiple app stores in 1 place
- [x] "Tested on J1 Ace" tags for trust
- [x] Works on Android 4.4 browser

## How to use
1. Search for the app you need
2. Click any store link: APKMirror, APKPure, etc
3. Download and install on your device
